# Eworks tarihsel arşivi

İlk tarayıcı entegrasyonu ana Eworks projesinden ayrı, `entegrasyon-1-tarayici/` altında korunur. Kaynak dosyaların içerikleri değiştirilmeden taşındı; `SOURCE-MANIFEST.json` ve eski Git dalı korunur.

Aktif ana proje **[ikinci entegrasyondur](../eworks/entegrasyon-2-servis/README.md)**. e-Defter geliştirmesi ve sonraki işler yalnız o yöntemde yürütülür. Arşive yeni özellik eklenmez ve canlı çalışma için bu arşiv başlatılmaz. Yerel özel ortamda da ilk sürüm, ikinci sürümden ayrı kardeş arşiv dizininde durur.

Şifre, gerçek müşteri verisi, PDF veya özel aktarım dosyası arşive eklenmez.
